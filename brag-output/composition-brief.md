# HyperFrames Composition Brief: AgentReel — C05 reel

## Objective
A vertical, narrated reel for brief C05 ("AI-ready graduate") that proves its claims with the pipeline's own run artefacts.

## Output
- Composition directory: `brag-output/composition/` (generated by `brag-output/build_reel.py` from the run)
- Rendered video: `brag-output/brag.mp4` → delivered as `G19_C05_final.mp4`
- Format: vertical — 1080x1920, 30 fps
- Duration: the run's timeline (≈ 50 s); user asked for ≤ 60 s, the brief for 45 s ±20 %

## Source Material
- Project root: `agentreel-G19/`
- Primary files read: `frontend/index.html` (palette, type, UI), `outputs/edit_meta.json` (scene + caption timing),
  `outputs/script.json`, `outputs/storyboard.json`, `outputs/facts.json`, `outputs/qa_report.json`,
  `logs/run_log.jsonl`, `briefs/C05.yaml`, `docs/screenshots/frontend_hero.png`, `outputs/frames/*.jpg`
- Product name: AgentReel (Group 19)
- Strongest claim: "This reel was planned, scripted and edited by agents built in that lab."
- Key UI to recreate: agent lane cards (frontend §01), terminal run log (frontend §07), QA checklist (§05), dashboard hero
- Copy that must appear verbatim: the brief CTA "Hire our AI-ready graduates today."; "Created with AI agents — LY Agentic AI Lab"

## Creative Direction
- Tone preset: polished — "show the receipts"
- Hook: frame 0 shows "What does an AI-ready graduate ___"; "build?" lands on the spoken word.
- Outro: CTA word by word, then end card (wordmark, CTA, disclosure).
- Avoid: generic SaaS language, invented numbers, mock dashboards, faces.

## Visual Identity
- Two-ink risograph on newsprint: paper #ede9e0 + fibre noise; blue #263a8c for all type and rules;
  scarlet #e8412c as the single accent (off-register text shadow on display lines, highlighter under the spoken word)
- Boxes are square 5 px blue rules on paper; no radius, no shadows, no gradients, no glow
- Display: Archivo 900 expanded (@font-face, assets/fonts/Archivo.ttf); body Archivo; data JetBrains Mono

## Storyboard
See `brag-plan.md`. One scene per VO line; scene windows and every caption word come from `edit_meta.json`.

## Audio
- Audio role: narrated; the pipeline's mixed VO + ducked procedural bed (`assets/audio/mix.wav`, −14 LUFS).
- SFX (Kenney CC0 from the /brag library): soft key ticks under streamed log lines, a soft impact on SEALED and on
  the QA badge, drops on deploy pills and checklist ticks, one bell on the end card — each at 0.35–0.6 volume.
- Music cue guidance: unavailable for strong-cue locks; narration is the clock.

## Hyperframes Instructions
Contract: one sub-composition per scene with `<template>`, `#root`, matching ids, paused timelines registered
after tweens, `fromTo` only, deterministic (the countdown is a tween of timeline time). Captions on one
`data-track-kind="captions"` host. Run `npx hyperframes check` before render.
